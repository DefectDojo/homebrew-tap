# DefectDojo Homebrew tap

```bash
brew install defectdojo/tap/earlylight
```

| Formula | What |
| --- | --- |
| `earlylight` | [Early Light](https://github.com/DefectDojo/earlylight): detect emerging vulnerabilities (eMudhra CA trust, PHP2Shell) in hosts, images and repositories |

Formulas install DefectDojo's signed release binaries and are checked against each release's `checksums.txt`.
